## 🔎 Project Overview

The **Hospital Emergency Room Dashboard** is an interactive data analysis project designed to transform hospital patient data into meaningful and easy-to-understand insights.

I designed this dashboard **from scratch** with a focus on:

✨ Interactive analysis  
📌 KPI-based reporting  
📊 Clear data visualization  
🎯 Easy-to-understand insights  
🔄 Monthly and yearly filtering  

The dashboard helps analyze patient admissions, age distribution, timeliness, gender, waiting time, satisfaction, and department referrals.

---

## 🎯 Project Objectives

The main objective of this project was to analyze emergency room patient data and create an interactive dashboard that can support quick performance monitoring and decision-making.

### Key areas analyzed:

🟢 **Patient Admission Status**  
🟢 **Patient Age Distribution**  
🟢 **Timeliness / Patient Attendance**  
🟢 **Gender-wise Analysis**  
🟢 **Department Referrals**  
🟢 **Average Waiting Time**  
🟢 **Patient Satisfaction**

---

## 📊 Key Analysis

### 🏥 1. Patient Admission Status

Analyzes the number and percentage of patients who were:

- 🟢 Admitted
- 🔵 Not Admitted

This provides an overview of the overall patient admission pattern.

---

### 👥 2. Patient Age Distribution

Patients are grouped into different age categories to identify how emergency room visits are distributed across different age groups.

---

### ⏱️ 3. Timeliness Analysis

Measures the percentage of patients who were seen within the expected time frame.

The dashboard compares:

- 🟢 Patients seen on time
- 🟠 Patients experiencing delays

This helps provide an overview of emergency room responsiveness.

---

### ⚥ 4. Gender Analysis

Provides a gender-wise analysis of patient visits to understand the distribution of patients by gender.

---

### 🩺 5. Department Referrals

Analyzes the number of patients referred to different hospital departments.

This helps identify departments receiving a higher volume of patient referrals.

---

## 📌 Dashboard KPIs

The dashboard provides important performance indicators including:

| KPI | Purpose |
|---|---|
| 👤 **Number of Patients** | Total patient volume |
| ⏱️ **Average Wait Time** | Average patient waiting time |
| ⭐ **Patient Satisfaction Score** | Overall satisfaction level |
| 🏥 **Admission Status** | Admitted vs. Not Admitted |
| ⚡ **Timeliness** | On-Time vs. Delayed patients |
